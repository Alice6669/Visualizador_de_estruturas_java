# Visualizador de Estruturas de Dados em Java

Trabalho final da disciplina **AED III (Algoritmos e Estruturas de Dados III)**. O projeto reúne implementações de estruturas de dados e algoritmos com interação pelo terminal, permitindo inserir, remover, buscar e visualizar elementos.

Desenvolvido em dupla por **Alice Lacerda** e **Isadora Rodrigues Canuto**.

## Funcionalidades

- **Árvore B**: inserção, remoção, busca e impressão da árvore. O grau mínimo é informado ao iniciar essa opção.
- **Árvore B+**: inserção, remoção, busca e impressão da árvore, também parametrizada pelo grau mínimo.
- **Árvore Trie**: operações com palavras, incluindo inserção, remoção, busca, verificação de prefixos, autocompletar e listagem das palavras armazenadas.
- **Merge Sort**: ordenação crescente de números inteiros, com opção de exibir as etapas da ordenação.
- **Busca binária**: busca de um elemento na lista ordenada e exibição dos passos percorridos.

A aplicação apresenta um menu principal para escolher entre as opções de árvores e a lista com ordenação e busca.

## Tecnologias

- Java
- JDK instalado
- IntelliJ IDEA (o repositório contém configuração de módulo do IntelliJ)

## Organização do código

O código-fonte está em `Trabalho final de AEDIII/src`:

- `Main.java`: menu principal e fluxo da lista com ordenação e busca.
- `Arvore_B/`: implementação e interface interativa da Árvore B.
- `Arvore_B_Mais/`: implementação e interface interativa da Árvore B+.
- `Arvore_Trie/`: implementação e interface interativa da Trie.
- `ordenacao/MergeSort.java`: algoritmo Merge Sort.
- `Busca_binaria.java`: busca binária com visualização dos passos.
